## L'Acoustics Amplifiers

HTTP Rest API

### Supported Devices

The module should work with all contemporary L'Acoustics amplifiers, with a minimum firmware of 2.16.
To date the following devices have been tested and confirmed working:

- LA1.16i
- LA2Xi

Please confirm functionality or report issues with other devices on the [git repo](https://github.com/bitfocus/companion-module-lacoustics-amplifiers/issues).

Available actions and feedbacks depend on the specific model being controlled

### Actions

- Output - Delay
- Output - Gain
- Output - Mute
- Output - Polarity
- Power
- Reboot

### Feedbacks

- Avdecc - Lock
- Avdecc - Entity Id
- Clock - Locked
- Clock - Status
- Clock - Type
- DSP Output - Mute
- DSP Output - Polarity
- DSP Output - Delay
- DSP Output - Gain
- DSP Output - Volume
- Level Meter - DSP Input
- Level Meter - DSP Output
- Levels - DSP Input
- Levels - DSP Output
- Power - Standby
- Power - SMPS Status
- Power - 24V In
- Power - 24V Out
- Power - Mains
- PTP - V2 Domain
- PTP - Primary
- PTP - Secondary
