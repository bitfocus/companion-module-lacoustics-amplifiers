## L'Acoustics Amplifiers

HTTP Rest API

Available actions and feedbacks depend on the specific model being controlled

### Actions

- Reboot
- Power
- Output - Delay
- Output - Gain
- Output - Mute
- Output - Polarity

### Feedbacks

- Avdecc - Lock
- Avdecc - Entity Id
- Clock - Locked
- Clock - Status
- Clock - Type
- DSP Output - Mute
- DSP Output - Polarity
- DSP Output - Delay
- DSP Output - Gain
- DSP Output - Volume
- Level Meter - DSP Input
- Level Meter - DSP Output
- Levels - DSP Input
- Levels - DSP Output
- Power - Standby
- Power - SMPS Status
- Power - 24V In
- Power - 24V Out
- Power - Mains
- PTP - V2 Domain
- PTP - Primary
- PTP - Secondary
